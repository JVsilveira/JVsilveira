# Projetos em Destaque

## Sistema de Estoque Regional

Sistema completo para gerenciamento de ativos e periféricos distribuídos por regiões do Brasil.

### Funcionalidades
- Controle por região
- Autenticação de usuários
- Estoques separados
- Cadastro de ativos e periféricos
- Controle administrativo

### Stack
- React
- Python
- PostgreSQL

---

## Auditoria de PDFs

Sistema de leitura automática de documentos PDF para auditoria e extração de dados.

### Funcionalidades
- Identificação automática de termos
- Extração de informações via Regex
- Verificação de assinatura
- Processamento em lote
- Geração de planilhas automatizadas

---

### Stack
- React
- Python
- PostgreSQL

## Bacteria

Aplicação Full Stack para gerenciamento e consulta de bactérias com armazenamento estruturado de dados microbiológicos.

---

### Funcionalidades
- CRUD de novas bactérias
- Validação no frontend com zod
- Velidação no backend
- Notificação com sonner

---

### Stack
- React
- Nest
- PostgreSQL
